# YELO — Product Overview

## Vision

YELO is a hyper-local social marketplace and community platform, initially targeting **Dehradun, Uttarakhand, India**. It combines five core experiences into one platform:

1. **Rent** — Peer-to-peer rental of physical items locally
2. **Buddy** — Social companionship marketplace for activities
3. **Forums** — College and community discussion boards
4. **Feed** — Social media-style home feed connecting the community

## Core Principle

> People nearby should be able to find things, people, and communities much faster than on traditional nationwide marketplaces.

This is NOT an OLX or nationwide marketplace. It is deeply optimized for **Dehradun and nearby users**.

## Target Market

- **Primary**: Dehradun, Uttarakhand
- **Users**: College students, young professionals, locals
- **Colleges**: Graphic Era Hill, Graphic Era Deemed, UPES, DIT University, DAV

## Key Differentiators

1. **Hyper-local** — Radius-based discovery, local relevance ranking
2. **Community-first** — Forums, social feed, college communities
3. **Safety** — Location privacy, moderation, anonymous posting with backend identity retention
4. **Trust** — Reviews tied to completed transactions, reputation system
5. **Free** — Built on free/open-source technologies

## MVP Scope

The MVP delivers end-to-end flows for all three verticals plus social features. Real payments are deferred; users settle offline. The architecture is designed to support payments, multi-city expansion, and mobile apps in future phases.

## Success Criteria

- A user can register, create a profile, and start using all features
- A user can list items for rent, request items, chat with owners, and complete rentals
- A user can offer buddy services, receive requests, chat, and complete sessions
- A user can join college forums, post (optionally anonymous), and discuss
- A user can browse a social feed with community-relevant posts
- Admin can moderate users, listings, forums, and handle reports
- Location privacy is enforced at the backend level
- Anonymous posting preserves user identity in the backend
